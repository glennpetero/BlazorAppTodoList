# Blazor Todo List

A responsive task-management web application built with C# and Blazor.

## Features
- Add, edit, and delete tasks
- Clean, responsive UI built with Razor components and Bootstrap
- Structured using standard .NET project and solution architecture

## Tech Stack
- **Framework:** .NET / Blazor
- **Language:** C#
- **Frontend:** Razor, HTML5, CSS3, Bootstrap

## How to Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/glennpetero/BlazorAppTodoList.git
   ```
2. Navigate to the project folder:
   ```bash
   cd BlazorAppTodoList
   ```
3. Run the application:
   ```bash
   dotnet run
   ```
